# لوحة تحكم البطاقات — تجمع حائل الصحي
> **Hail Health Cluster — Emergency Cards Dashboard**

لوحة إلكترونية لإدارة الأزمات والكوارث واستمرارية الأعمال بتجمع حائل الصحي: توثيق الحوادث الطارئة فوراً، وطباعة بطاقات رسمية بتنسيق A4، وأرشفة كل حادثة مع مؤشرات أداء تلقائية.

- **التشغيل:** افتح `index.html` مباشرة في المتصفح — لا يحتاج خادماً ولا تثبيتاً ولا إنترنت
- **اللغة:** عربي بالكامل (RTL) — خط Cairo مضمّن محلياً
- **التخزين:** في متصفح الجهاز فقط (`localStorage`) — لا تُرسل أي بيانات لأي خادم
- **زر الرجوع في المتصفح** يعود للبطاقة السابقة، ورابط مثل `index.html#fire` يفتح البطاقة مباشرة
- **الوضع الفاتح والداكن:** زر في الشريط العلوي، ويُحفظ اختيار كل جهاز (الافتراضي يتبع إعداد النظام)
- **التثبيت كتطبيق (PWA):** عند فتح اللوحة عبر خادم ويب يمكن تثبيتها وتعمل بلا إنترنت

## سير العمل

1. افتح البطاقة المطلوبة وعبّئ الحقول. المعاينة تتحدث فوراً، والمسودة تُحفظ تلقائياً
2. **حفظ في السجل** (زر الحفظ أو `Ctrl+S`): يحفظ نسخة كاملة من البطاقة في الأرشيف
3. **طباعة** (زر الطباعة أو `Ctrl+P`): A4، واسم الملف يتولّد تلقائياً
4. قبل الطباعة أو الحفظ تتحقق اللوحة من:
   - تعبئة الجهة والتاريخ
   - تسلسل الأوقات: البداية ← الإبلاغ لصحة 8 ← الانتهاء

   تُميَّز الحقول المخالفة باللون الأحمر، ويبقى قرار المتابعة للمستخدم

### السجل والإحصائيات
- **فتح:** يعيد أي حادثة محفوظة إلى بطاقتها كاملة لمراجعتها أو إعادة طباعتها
- **بحث:** بالجهة أو النوع أو أي نص داخل البطاقة
- **مؤشرات الفترة:** متوسط زمن الإبلاغ لصحة 8، متوسط مدة الحدث، مجموع الحالات حسب الفرز، الحوادث حسب الجهة
- **تصدير Excel (CSV):** للفترة والبحث الحاليين، مع الأوقات والمؤشرات لكل حادثة
- السجلات المحفوظة قبل أكتوبر 2026 لا تحتوي نسخة كاملة، فلا تُفتح ولا تدخل في حساب الأزمنة

### النسخ الاحتياطي
- من الصفحة الرئيسية: **نسخة احتياطية** تصدّر كل البيانات (القوائم والسجل والمسودات) في ملف JSON
- **استعادة** تستبدل كل البيانات الحالية بمحتوى الملف
- البيانات محفوظة في متصفح الجهاز فقط، لذلك:
  - حذف بيانات المتصفح يمحوها
  - النسخة الاحتياطية هي الطريقة الوحيدة لنقلها إلى جهاز آخر

## للمطوّر

- **التصميم:** الواجهة مبنية على قواعد [taste-skill](https://github.com/leonxlnx/taste-skill) لشاشات التطبيقات
  - كل الألوان رموز في `css/09-theme.css` (`--ground` `--surface` `--text` `--accent`...) لكل وضع
  - لون واحد للتمييز (أزرق التجمع) على البيانات والإجراء الرئيسي فقط، وألوان أكواد الطوارئ على قائمة البلاغات
  - بلا تدرجات ولا زجاج ولا ظلال على العناصر الثابتة، والعناوين بحالة الجملة لا بأحرف كبيرة متباعدة
  - **الوصول** وفق [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): تباين 4.5:1 في الوضعين، كل حقل له اسم مقروء، أهداف لمس 44px وحقول 16px على الجوال
  - **بطاقات A4 خارج الثيم:** تبقى كما هي في الوضعين وعند الطباعة

- **ترتيب السكربتات مهم:** كل ملف في `js/` يعتمد على ما قبله (سكربتات عادية تتشارك النطاق العام)
- **القوائم القابلة للتخصيص:** معرّفة في `CONFIG_LISTS` داخل `js/08-core.js`
  - لإضافة قائمة جديدة: أضف سطراً واحداً، فتتولد دالتا `getX()` و`saveX()` تلقائياً
- **Service Worker:**
  - ملفات الموقع تُجلب من الشبكة أولاً، فيصل التعديل للمستخدمين فوراً
  - الصور والخطوط تُقرأ من التخزين المؤقت أولاً
  - **عند إضافة ملف أو حذفه:** حدّث `CORE_FILES` وارفع `CACHE_VERSION` في `sw.js`
- **إدارة الإصدارات:** المشروع تحت Git
  - كل تعديل في commit مستقل
  - للتراجع: `git log` ثم `git revert <commit>`
- **الطباعة:**
  - أنماط `@media print` في ملفات css
  - كل `@media` خاص بالشاشة مقيّد بـ `screen and` حتى لا يؤثر على الطباعة من الجوال
- **الألوان الرئيسية:** `#003D5C` / `#005B82` أزرق داكن · `#00AEEF` أزرق فاتح · `#B71C1C` أحمر طوارئ · `#E8C800` أصفر
